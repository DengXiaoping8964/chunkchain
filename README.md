# 区块连锁 ChunkChain

Minecraft **1.18.2 Fabric** 的「同位置跨区块连锁挖掘」模组。

挖掉一个方块后，以它在区块内的相对位置 `(x & 15, y, z & 15)` 为模板，在以该方块所在区块为中心的 **N×N 区块** 范围内，把同一相对位置上的方块连锁挖掉——**不看方块种类，按位置来**。掉落物按原版规则原地掉落（用你手上的工具计算，支持时运/精准采集）。

## 功能

- 范围可选：3×3 / 5×5 / 7×7 / 9×9 / 11×11 区块
- 可随时开关
- 你亲手挖掉的每个方块都会成为一次模板（挖多个 = 多次连锁）
- 跳过：空气、流体、不可破坏方块（基岩/屏障等）、未加载的区块
- 掉落物原地生成，走原版掉落表

## 操作

| 操作 | 默认键 | 命令 |
| --- | --- | --- |
| 开关 | `V` | `/cc on`、`/cc off`、`/cc toggle` |
| 切换范围 | `B` | `/cc cycle` |
| 指定范围 | — | `/cc size 3\|5\|7\|9\|11` |
| 查看状态 | — | `/cc status` |

状态会在动作栏提示。按键可在「选项 → 控制」中修改。

## 构建

- JDK 17、Gradle 8.7、Fabric Loom 1.6.12
- `build.cmd` 里使用了本机路径，可按自己的环境修改，或直接执行 `gradle build`
- 产物：`build/libs/chunkchain-1.0.0.jar`
- 运行时依赖：Fabric Loader ≥ 0.14.0、Fabric API（1.18.2 对应 0.77.0+1.18.2）

## 已验证

Minecraft 1.18.2 + Fabric Loader 0.14.21 + Fabric API 0.77.0 实机验证：

- 3×3：8/8 邻块连锁挖掉；范围外保持原样；掉落物落在对应位置
- 关闭：4/4 邻块保持
- 5×5：24/24（半径 2 区块）连锁挖掉

## 说明

- 连锁不消耗工具耐久
- 以挖掉方块所在区块为**中心**（N 为奇数，左右对称）
- 未加载的区块会被跳过，不强制加载
